# Identidade Visual — Ritmo da Marca

## Paleta de Cores
| Código | Uso |
|--------|-----|
| `#1a0533` | Fundo principal |
| `#6e00d4` | Roxo vibrante — destaque |
| `#a855f7` | Roxo médio |
| `#ffffff` | Texto |
| `#f3e8ff` | Fundo suave |

> Use essas 5 cores em TODOS os posts para consistência visual imediata e reconhecimento de marca.
